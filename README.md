# toshichanapp 👋

不動産・建築向け VR/360°パノラマ SaaS「スペースリー」の **プラットフォームエンジニア**。
Web アプリ（Ruby on Rails / Vue.js）からクラウドインフラ（AWS / GCP・Terraform IaC）まで、
**アプリ層とインフラ層を横断**して開発・運用しています。2021年からこれまでに 5 リポジトリで **1,800+ PR** をマージ。

## 🛠 技術領域

| 領域 | 主な技術 |
|---|---|
| Backend | Ruby on Rails, Sidekiq / Sidekiq Pro |
| Frontend | Vue.js (2/3), TypeScript, Chrome拡張 (WXT / Manifest V3) |
| Infra (AWS) | ECS/Fargate, Lambda, Step Functions, S3, RDS/Aurora, CloudFront, IAM(OIDC) |
| Infra (GCP) | BigQuery, Workload Identity Federation |
| IaC / CI/CD | Terraform / HCP Terraform, GitHub Actions, ecspresso, Docker |
| Data / Observability | DuckDB, MySQL, Datadog (APM / SLO) |

## 🚀 最近の主な取り組み

- **EC2 → ECS/Fargate への全面移行** をアプリ＋インフラ横断で主導
- **ストレージ使用量分析基盤の DuckDB 移行**（レポート出力を 約1週間 → 約9分 に短縮）
- **不動産情報基幹システムとの連携基盤**（サーバ API ＋ Chrome 拡張）をゼロから構築
- **Datadog によるエラーバジェットベースの SLO 監視基盤** を構築
